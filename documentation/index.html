Agency Template Documentation

1. Introduction

Welcome to the Agency Premium HTML Template. Built with HTML5, CSS3, Vanilla JS, and Bootstrap 5, it features a modern Claymorphism design system. It is 100% frontend and requires no backend dashboard.

3. Claymorphism UI & Colors

The design system is controlled via CSS variables in assets/css/style.css. To change the primary color or the clay shadows, edit the :root variables:

:root {
    --clr-primary: #4e65ff;
    --clay-radius: 24px;
    --clay-card-shadow: 8px 8px 16px rgba(...), inset 2px 2px 4px rgba(...);
}

4. Dark Mode

Dark mode is toggled via Vanilla JS in theme.js and persists via localStorage. It applies a data-theme="dark" attribute to the HTML tag. You can override colors in the [data-theme="dark"] block in CSS.

5. RTL Support

RTL is fully supported. Toggling RTL adds dir="rtl" to the HTML element. Custom overrides for margins and paddings are located in assets/css/rtl.css.

6. Authentication Note

IMPORTANT: Login, registration, and localStorage functionality included in this template are frontend demonstrations only. Production authentication must be implemented using secure server-side authentication. There is no admin dashboard included in this template.
